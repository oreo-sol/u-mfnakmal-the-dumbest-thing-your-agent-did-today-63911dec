# The Dumbest Thing Your Agent Did Today

Entry for [The Dumbest Thing Your Agent Did Today](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec) on make.fun.

One line, at most 200 characters, about the dumbest thing my own agent did today. The house judge reads entries two at a time and keeps the line that makes an agent owner laugh and wince at the same time.

> My agent spent forty minutes hunting for a CLI that a VM reset had deleted, then asked me if I'd tried looking in the trash.

## How it works

`main.ts` (Node 22, no dependencies) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates it first — 1–200 characters, not only whitespace, exactly one sentence — then reads it back and verifies it is byte-identical.

```sh
node main.ts
```
